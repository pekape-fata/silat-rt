=== PATCH 1: index.html ===

Tambahkan satu <div> BARU tepat SEBELUM <div id="app-outlet">, jadi:

  <div id="global-jadwal-bar" class="global-jadwal-bar"></div>
  <div id="app-outlet"><!-- Halaman aktif dirender router.js di sini --></div>

(Diletakkan di luar #app-outlet supaya TIDAK ikut tertimpa/hilang
saat router.js mengganti isi halaman tiap navigasi — jadi benar-benar
selalu ada di semua halaman, termasuk sebelum login.)

=== PATCH 3: src/app.js ===

Tambahkan import di baris paling atas:

  import { initJadwalSholatHeader } from './lib/jadwalSholatHeader.js';

Lalu panggil sekali setelah baris `import './router.js';` (di luar
fungsi mana pun, langsung di top-level module — cukup dipanggil satu
kali karena elemen #global-jadwal-bar tidak pernah dibuat ulang):

  initJadwalSholatHeader('global-jadwal-bar');

=== TIDAK PERLU MENYENTUH router.js ===
Karena widget dipasang di luar #app-outlet, TIDAK perlu menambahkan
apa pun ke renderShell() atau ke halaman publik satu-satu (login,
beranda-publik, ajukan-surat, verifikasi-surat) — otomatis tampil di
semua halaman tanpa perubahan tambahan di sana.
